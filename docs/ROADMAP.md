# 产品路线图

## 愿景

让 OpenClaw AI 拥有完整的"身体"，能够看、听、说、做。

---

## 当前状态 (v0.x)

### ✅ 已实现

| 能力 | 状态 | 说明 |
|------|------|------|
| Live2D | 可用 | 桌面伴侣，表情和动作 |
| TTS (Qwen) | 可用 | 高质量中文语音合成 |
| Vision | 可用 | 屏幕截图 |

### 🚧 进行中

- 架构重构 (Monorepo + gRPC)
- TTS 多提供商支持

---

## v1.0 - 基础身体

### 目标

完成架构重构，建立稳定的能力插件系统。

### 里程碑

- [ ] Monorepo 结构
- [ ] gRPC 通信协议
- [ ] 能力插件接口
- [ ] TTS 多提供商 (Qwen, Edge-TTS)
- [ ] mDNS 服务发现
- [ ] HTTP 兼容层
- [ ] 完整文档

---

## v1.1 - 耳朵 (Microphone)

### 目标

添加语音输入能力，让 AI 能够"听"。

### 功能

- [ ] 麦克风音频捕获
- [ ] 音频流传输
- [ ] 静音检测
- [ ] 多设备支持

### 技术方案

- PulseAudio / ALSA 集成
- WebRTC VAD (语音活动检测)
- Opus 编码传输

---

## v1.2 - 手 (Executor)

### 目标

添加脚本执行能力，让 AI 能够"做"。

### 功能

- [ ] Shell 命令执行
- [ ] Python 脚本执行
- [ ] 沙箱隔离
- [ ] 权限控制
- [ ] 执行日志

### 安全考虑

- 白名单命令
- 资源限制 (CPU, 内存, 时间)
- 网络隔离选项

---

## v2.0 - 增强感知

### 目标

增强视觉和听觉能力。

### 功能

#### 视觉增强

- [ ] 实时屏幕监控
- [ ] OCR 文字识别
- [ ] 窗口/区域选择
- [ ] 多显示器支持

#### 听觉增强

- [ ] 语音转文字 (STT)
- [ ] 说话人识别
- [ ] 情感分析
- [ ] 多语言支持

---

## v2.1 - 多模态输出

### 目标

丰富输出方式。

### 功能

- [ ] 图片生成/显示
- [ ] 视频播放
- [ ] 音效播放
- [ ] 通知系统
- [ ] 剪贴板操作

---

## v3.0 - 分布式身体

### 目标

支持多设备协同，身体部件可以分布在不同设备上。

### 功能

- [ ] 多 Body 实例协同
- [ ] 能力负载均衡
- [ ] 故障转移
- [ ] 跨网络通信

### 场景

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Desktop   │     │   Server    │     │   Mobile    │
│   Live2D    │     │   TTS/STT   │     │   Camera    │
│   Vision    │     │   (GPU)     │     │   Mic       │
└─────────────┘     └─────────────┘     └─────────────┘
       │                  │                   │
       └──────────────────┴───────────────────┘
                          │
                    ┌─────────────┐
                    │   Brain     │
                    │  (OpenClaw) │
                    └─────────────┘
```

## 贡献指南

欢迎贡献新的能力模块！

1. 查看 [开发指南](./DEVELOPMENT.md)
2. 提交 Issue 讨论新功能
3. 实现并提交 PR

### 优先级

| 优先级 | 说明 |
|--------|------|
| P0 | 核心功能，阻塞发布 |
| P1 | 重要功能，当前版本 |
| P2 | 有价值，下个版本 |
| P3 | 未来考虑 |
